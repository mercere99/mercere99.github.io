Build and run locally

In the directory containing this HTML file and the WAT file:

wat2wasm hypotenuse.wat -o hypotenuse.wasm
python3 -m http.server 8000 --bind 127.0.0.1

Open http://localhost:8000/hypotenuse.html. Rebuild the binary and reload the page after changing the WAT source.
